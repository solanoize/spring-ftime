# Spring FTime

A hands-on journey to explore how modern Java applications are built with the power of the Spring ecosystem.

It's my personal playground to understand how things like dependency injection, REST APIs and data persistence come together in a real-world setup.

## Run Test

If you need to test this app, you can run the following command:

```
mvn clean test
```

## Run Application

Build the project:

```
./mvnw clean package
```

Run the application:

```
java -jar target/spring-ftime-0.0.1-SNAPSHOT.jar
```

Or:

```
mvn spring-boot:run
```
